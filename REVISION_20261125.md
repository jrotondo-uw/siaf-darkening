# November 25, 2026 revision

This revision corrects observational spatial weighting, replaces the primary historical model-only uncertainty with an observed-minus-common-MMM residual spread, and replaces the leakage diagnostic's month-specific contrast with a fixed 0.54 reference contrast.

## Main numerical changes

For CERES APRP, 1982–2014, the corrected globally averaged annual SIAF is 0.209822 W m−2 K−1: 0.138269 from the area-loss component and 0.071553 from the darkening component (34.1%). The primary residual-based 2σ half-widths are 0.053794, 0.031832 and 0.025549 W m−2 K−1, respectively. The family-weighted model mean remains approximately 40% below the observational center. The model member estimates were not changed by this observational correction.

The uncertainty calculation subtracts the common family-weighted CMIP6 calendar-time trend from the observed annual radiative-anomaly series, retains the remaining trend disagreement, and uses 10,000 circular block resamples with three-year blocks and the observed temperature sequence held fixed. One- and five-year block checks are included. This is a conditional residual-variability estimate, not pure internal variability, a complete measurement-error budget, or a calibrated 95% confidence interval. Radiative sensitivity remains climatological in this calculation. The older model-only calculation remains available as a separate comparison; the two widths are not added.

The historical annual comparison, full-domain ice sensitivity, and Figure 5 monthly observational points use their own residual-based estimates. Extended-record, map, threshold-sensitivity, and local-footprint sampling diagnostics are explicitly separate. A global SIAF width must not be rescaled indiscriminately into another metric.

## Spatial weighting

Each 25 km polar-stereographic ocean cell within the ≥60°N analysis domain now receives the nearest source radiative-sensitivity value. This is remapping, not new 25 km radiative information. The integration uses polar-stereographic cell-area weights, includes component zeros, and retains a fixed domain denominator. The earlier coarse-source-to-fine-target placement left most fine cells empty and sampled an irregular subset.

A separate cell-overlap integration check gives 0.209791 versus 0.209822 W m−2 K−1 for historical CERES (0.015% difference); the analogous ERA5-kernel difference is about 0.010%. The overlap calculation uses fine-cell area quadrature and is a sensitivity check, not a replacement for the primary implementation.

## Reproduction

From the repository root:

```
python reproducibility/reproduce_residual_uncertainty.py
python figures/f05_ab_source_data.py
python figures/f07_observed_source_data.py
python figures/s05_source_data.py
python figures/run_one.py f02
python figures/run_one.py f05
python figures/run_one.py f06
python figures/run_one.py f07
python figures/run_one.py f08
python figures/run_one.py s05
```

The first command reproduces all deposited SIAF, full-IS and monthly Figure 5 residual widths without HPC access. The figure commands read curated inputs included in `figures/` and `analysis_data/`. Full observational reprocessing in `python/siaf_obs_analysis.py` additionally needs the original satellite/reanalysis files and caches; set its `SIAF_DIR_SIAL`, `SIAF_DIR_APPX`, `SIAF_DIR_SIC`, `SIAF_CACHE_CMIP6`, `SIAF_CACHE_OBS`, `SIAF_CERES_FILE`, `SIAF_KERNEL_FILE`, `SIAF_GISTEMP_PATH`, `SIAF_COWTANWAY_PATH`, `SIAF_NCEP_PATH`, and `SIAF_ERA5_GLOB` environment variables as applicable. Cache-directory overrides must include a trailing separator because the original cache loaders concatenate filenames. `SIAF_OUT_DIR` selects the output directory; its default is a local `output/observational_weighting` directory. Defaults for input files retain the original Derecho provenance.

## Data permissions

Raven/SLEIGH individual observations and matchup pairs are excluded from this new release. Aggregate Figure 9 statistics remain available, and individual data are available upon request to their providers, subject to permission. Previously published archive versions are not altered. Tara QA-treated data retain the documented later DAMOCLES redistribution permission and attribution in the Tara README; the original radiometer workbook is excluded.
