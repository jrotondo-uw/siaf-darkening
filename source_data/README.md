# Figure source data

The numbered CSVs provide the available numerical data for the manuscript and supplementary figures.

Individual Raven/SLEIGH reference observations and collocated pairs are excluded from `SourceData_Supplementary_Figure11.csv` because public redistribution permission has not been established. These data are available upon request to the data providers, subject to permission. The aggregate validation statistics remain in `SourceData_Figure9.csv`.

Tara QA-treated data retain the DAMOCLES credit and redistribution-permission statement recorded in `validation/tara_surface_flux/README_broadband.md`. The original radiometer workbook is not included.

This source-data package does not grant reuse rights beyond the licenses or permissions of the original data providers.
