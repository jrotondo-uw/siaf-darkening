# Figure source data

The 30 numbered CSVs provide the available numerical data for the manuscript and supplementary figures.

Individual Tara and Raven/SLEIGH reference observations, coordinates and collocated pairs are excluded from this release. These data are available upon request to the data providers, subject to permission. The aggregate validation statistics remain in `SourceData_Figure9.csv`.

Tara processing code and aggregate statistics retain DAMOCLES credit. The original radiometer workbook, coordinate file and QA-treated individual records are not included.

This source-data package does not grant reuse rights beyond the licenses or permissions of the original data providers.
